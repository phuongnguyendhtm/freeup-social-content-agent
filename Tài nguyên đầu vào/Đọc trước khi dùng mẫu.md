# Dùng mẫu để chuẩn bị tư liệu

Ngay khi tải và giải nén, mỗi thư mục Ảnh cá nhân, Ảnh nhân vật, Video nền có Mẫu tham khảo gồm ba file từ bản gốc FreeUp. Nhạc nền/Nhạc từ bản gốc giữ 14 bài nhạc.

Xem mẫu để biết cần bổ sung gì, rồi chép file của bạn vào thư mục cùng loại và nêu tên file trong 9BizClaw. Mẫu không phải thông tin hay hình ảnh của học viên. Muốn thử bằng mẫu, nói rõ “Dùng mẫu ... để thử”. Không suy ra hồ sơ thương hiệu từ các file mẫu.

Không cần API Pexels/Gemini để dùng file có sẵn. Xem API và tài nguyên mẫu.md ở thư mục gốc.
