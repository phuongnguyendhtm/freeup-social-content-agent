# Nghiệm thu bản rút gọn

- Lưu bài trực tiếp, không cần tài khoản dịch vụ hoặc duyệt sản xuất/đăng.
- Chat, caption.txt và nội dung lấy lại phải khớp nhau; sửa cùng mã phải giữ phiên bản.
- Render ảnh/carousel/infographic/video bằng engine local và tài nguyên FreeUp.
- Nâng dữ liệu 1.0 giữ nội dung và bỏ trạng thái nghiệp vụ cũ khỏi luồng mới.
- Cài lại giữ dữ liệu, dọn mã tích hợp cũ và xác minh host nhận skill.
- Chỉ xác nhận host thật đã thử; fixture bốn host không thay thế bốn phiên agent thật.
